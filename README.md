# wedding

wedding invitation (React)

## 최초 설치 & 설정

```sh

# 최초 설치 CRA 활용
$ yarn create react-app ./ --template typescript

# node_module은 필요없으므로 삭제
# ZipFS 플러그인 설치
# yarn 버전을 berry로 변경
$ yarn set version berry

# 타입스크립트 연결 -> .vscode 아래 파일 생성됨. 명령어 입력후 allow.
$ yarn dlx @yarnpkg/sdks vscode

# eslint와 prettier를 vscode가 잘 읽을 수 있게 하기.
$ yarn dlx @yarnpkg/sdks vscode

# json-server 생성 (db.json기반)
$ yarn dev:db

```
